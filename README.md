# AZL HAIL

موقع ثابت باللغة العربية لشركة AZL HAIL، مكتوب بـ HTML وCSS وJavaScript دون إطار عمل أو اعتماد على خادم خلفي.

## معاينة محلية

افتح الموقع عبر خادم محلي، ولا تفتح ملف `index.html` بالنقر المزدوج (`file://`). الصفحات تستخدم مسارات من جذر الموقع، لذلك فتحها كملفات منفردة يعرض النص بلا CSS ويكسر مسارات الصور.

1. افتح مجلد المشروع في Visual Studio Code.
2. ثبّت إضافة **Live Server** إذا لم تكن مثبتة.
3. افتح `index.html` ثم اختر **Open with Live Server**.
4. ستفتح المعاينة المحلية. مسار الموقع لا يعتمد على عنوان محلي ثابت.

بديل دون إضافة: تأكد من وجود Node.js ثم شغّل `node tools/preview.mjs` داخل المجلد، وافتح `http://127.0.0.1:5500/`.

## هيكل الملفات

- `index.html`: الصفحة الرئيسية.
- مجلدات بأسماء عربية: صفحات الخدمات والمعلومات.
- `assets/images/`: صور ويب محسنة بأسماء واضحة.
- `backup/original-photos/`: نسخ احتياطية من الصور الأصلية بأسمائها الأصلية.
- `assets/logo/`: الشعار الكامل والرمز المعماري.
- `assets/icons/`: شعار WhatsApp ورمز الهاتف المستخدمان في أزرار التواصل.
- `css/style.css`: الأنماط والتجاوب والحركات.
- `js/main.js`: قائمة الجوال ومعرض الصور.
- `tools/generate-pages.mjs`: مولّد الصفحات الثابتة وملفي robots وsitemap.

## تحديث الصفحات

تُحرر النصوص ومواصفات الخدمات في `tools/generate-pages.mjs` ثم يشغل `node tools/generate-pages.mjs` لإعادة إنشاء ملفات HTML. احتفظ بنسخة من التغييرات قبل إعادة التوليد.

## النشر على Vercel

ارفع محتويات المجلد إلى مستودع GitHub يدويًا، ثم اربط المستودع بمشروع Vercel واختر إعداد نشر ثابت دون أمر بناء أو مجلد إخراج منفصل. قبل الإطلاق، حدّث متغير `SITE` في `tools/generate-pages.mjs` إلى النطاق الفعلي، ثم أعد التوليد وانشر `sitemap.xml` المحدّث. لم تتم تهيئة Git ولم يُرفع المشروع.

## معلومات تحتاج اعتماد المالك

- تأكيد نطاق الموقع الرسمي بدل `azl-hail.vercel.app` المؤقت.
- التحقق مما إذا كانت الصور لعمليات نفذتها الشركة أم صورًا توضيحية؛ تعرض حاليًا بوصفها صورًا توضيحية.
- اعتماد أي تفاصيل للضمان والخبرة قبل إضافتها.
- تزويد رابط مباشر لتقييمات Google إذا رغبت الشركة في عرضه.
- تأكيد صلاحية المواد للخزانات المخصصة لمياه الشرب عند تقديم هذه الخدمة.
